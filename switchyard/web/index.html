How it works

      
    
        
  1. Scan the repo's code for every OpenAI, Anthropic, LiteLLM, LangChain and Vercel AI SDK call, in Python and JS/TS. No code is executed.
    2. 
        
  2. Investigate: a Super agent with search and read-file tools finds who calls each one and with what real inputs.
    3. 
        
  3. Understand each call: Super describes the task, inputs and output contract.
    4. 
        
  4. Test: Ultra (reasoning on) writes typical + tricky cases and the ideal answers. Tavily supplies real-world inputs.
    5. 
        
  5. Evaluate Lightning, Super and Ultra on every case: hard format checks in code plus a Super grader.
    6. 
        
  6. Repair: if a cheaper model nearly passes, Ultra adapts the prompt and it is re-tested.
    7. 
        
  7. Patch: rewrite each call to the cheapest model that clears the bar, compile-check it, and produce a reviewable diff.
    8. 
        
  8. Run the code: call each switched function from the patched code against Token Factory and record the requests.
    9. 
        
  9. Audit: check for leaked keys and unsafe use of model output, then attack each switched prompt with injection probes on its new model.
    10.

Most apps send every call to one frontier model. Many of those calls are classification, extraction or short summaries that a smaller open model handles just as well. Switchyard finds each call, tests it on the NVIDIA Nemotron family, and only switches the calls that pass.
